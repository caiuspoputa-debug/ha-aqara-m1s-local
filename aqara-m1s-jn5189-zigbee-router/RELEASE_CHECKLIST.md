# GitHub release checklist

- [ ] Remove or anonymize private IP addresses.
- [ ] Remove MiIO tokens, Zigbee keys, HomeKit secrets, and credentials.
- [ ] Review every screenshot.
- [ ] Confirm the NXP SDK license permits binary redistribution.
- [ ] Add the firmware binary only if redistribution is permitted.
- [ ] Generate SHA-256 and MD5 checksums.
- [ ] State exact hub, SDK, IDE, coordinator, and channel versions.
- [ ] State clearly that recovery is not guaranteed.
