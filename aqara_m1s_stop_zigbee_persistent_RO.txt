Aqara M1S - Oprire Zigbee Aqara persistent

Scop:
- Hubul porneste normal pe Wi-Fi.
- Telnet ramane activ automat.
- Zigbee Aqara este oprit automat dupa pornire.
- HomeKit, lumina si sunetul raman active.
- mzigbee_agent si app_monitor.sh nu mai ruleaza dupa boot.

Testat pe:
- 192.168.0.44
- 192.168.0.101


============================================================
1. Verificare Zigbee activ
============================================================

Pe hub, in Telnet:

ps w | grep mzigbee
ps w | grep app_monitor

Daca vezi:

mzigbee_agent -f /etc/mzigbeeAgent.conf

inseamna ca Zigbee Aqara ruleaza.

Daca vezi doar:

grep mzigbee

inseamna ca Zigbee Aqara este oprit.


============================================================
2. Test manual fara reboot
============================================================

Ruleaza pe hub:

killall app_monitor.sh 2>/dev/null
killall mzigbee_agent 2>/dev/null
sleep 5
ps w | grep mzigbee
ps w | grep app_monitor

Rezultat corect:

- la mzigbee apare doar linia cu grep
- la app_monitor apare doar linia cu grep


============================================================
3. Script persistent cu oprire Zigbee
============================================================

Ruleaza pe hub:

mkdir -p /data/scripts

cat > /data/scripts/post_init.sh <<'EOF'
#!/bin/sh

fw_manager.sh -r &

(
    i=0
    while [ $i -lt 120 ]; do
        IP="$(ifconfig wlan0 2>/dev/null | grep 'inet addr')"
        if [ "$IP" != "" ]; then
            sleep 5
            fw_manager.sh -t -k &

            # disable Aqara Zigbee service 5 sec after Telnet start
            sleep 5
            killall app_monitor.sh 2>/dev/null
            killall mzigbee_agent 2>/dev/null

            exit 0
        fi
        sleep 2
        i=$((i+2))
    done

    fw_manager.sh -t -k &

    # fallback: disable Zigbee 5 sec after Telnet start
    sleep 5
    killall app_monitor.sh 2>/dev/null
    killall mzigbee_agent 2>/dev/null
) &

exit 0
EOF

chmod +x /data/scripts/post_init.sh
sync


============================================================
4. Verificare script
============================================================

Ruleaza:

cat /data/scripts/post_init.sh

Trebuie sa inceapa cu:

#!/bin/sh

si sa se termine cu:

exit 0


============================================================
5. Reboot
============================================================

Cand esti pregatit:

reboot


============================================================
6. Verificare dupa reboot
============================================================

Intra din nou pe hub:

telnet IP_HUB

Apoi verifica:

ps w | grep telnet
ps w | grep mzigbee
ps w | grep app_monitor
ps w | grep homekit
ps w | grep mha

Rezultat dorit:

telnetd = prezent
mzigbee_agent = absent, apare doar grep
app_monitor.sh = absent, apare doar grep
homekitserver = prezent
mha_basis = prezent
mha_master -b = prezent


============================================================
7. Revenire - pornire Zigbee din nou
============================================================

Daca vrei sa anulezi oprirea Zigbee, editeaza scriptul:

vi /data/scripts/post_init.sh

Sterge blocurile:

killall app_monitor.sh 2>/dev/null
killall mzigbee_agent 2>/dev/null

sau rescrie scriptul doar cu Telnet persistent, fara oprire Zigbee.

Apoi:

sync
reboot


============================================================
8. Observatii
============================================================

- Nu opri homekitserver.
- Nu opri mha_basis.
- Nu opri mha_master.
- Nu opri miio_client.
- Pentru HomeKit, lumina si sunet, aceste servicii trebuie sa ramana active.
- Pentru reducerea zgomotului Zigbee langa Zigbee2MQTT, procesul important de oprit este mzigbee_agent.
- app_monitor.sh reporneste mzigbee_agent, deci trebuie oprit si el.
